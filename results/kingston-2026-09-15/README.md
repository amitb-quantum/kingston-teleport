# Curated result bundle

This directory contains the redacted, Git-trackable artifacts for the
2026-09-15/16 UTC IBM Kingston run. It intentionally excludes credentials and
the complete transient `runs/` directory.

- `main/`: preregistered 18-circuit experiment, raw joint counts, analyses,
  plots, preflight, and IBM job metrics.
- `register-diagnostic/`: post-hoc isolated register/correction controls.
- `sequence-diagnostic/`: post-hoc two-conditional ordering controls.
- `SHA256SUMS`: integrity hashes for every curated artifact other than the hash
  file itself.

See the repository-level `RESULTS.md` for interpretation and limitations.
